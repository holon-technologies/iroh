Module endpoint 

Source
Expand description

The Endpoint allows establishing connections to other krikos endpoints.

The Endpoint is the main API interface to manage a local krikos endpoint. It allows connecting to and accepting connections from other endpoints. See the module docs for more details on how krikos connections work.

The main items in this module are:

  • Endpoint to establish krikos connections with other endpoints.
  • Builder to create an Endpoint.

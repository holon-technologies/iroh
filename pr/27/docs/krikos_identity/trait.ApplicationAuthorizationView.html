Expand description

Exact, read-only authorization facts used to verify an application envelope.

Implementations represent an already authenticated account checkpoint. This interface performs no network or wall-clock access and deliberately does not claim that the checkpoint is globally fresh. A caller that requires freshness must establish it before constructing the view.

Evaluate account and caller freshness requirements without permitting caller weakening.

Provider maximum age is measured from the signed checkpoint-log observation to the explicit verifier time. A later tree head proves continued inclusion but cannot refresh the checkpoint’s original observation. The checkpoint’s account-supplied metadata timestamp is never an authority source. LatestKnown establishes only the exact locally trusted checkpoint context.

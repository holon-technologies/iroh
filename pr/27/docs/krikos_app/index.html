Experimental local-first application lifecycle.

This crate is intentionally unpublished while the framework’s public name and API are being evaluated. It provides an atomic lifecycle boundary: configuration and identity are validated before components start, partially started applications are rolled back, and one supervisor owns runtime failure and bounded shutdown.

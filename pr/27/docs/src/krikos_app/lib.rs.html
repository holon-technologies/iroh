1//! Experimental local-first application lifecycle.
2//!
3//! This crate is intentionally unpublished while the framework's public name and API are being
4//! evaluated. It provides an atomic lifecycle boundary: configuration and identity are validated
5//! before components start, partially started applications are rolled back, and one supervisor
6//! owns runtime failure and bounded shutdown.

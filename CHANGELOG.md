# Changelog

This fork's release notes, starting at `1.0.0`, are generated by
[git-cliff](https://git-cliff.org) from Conventional Commits and are
prepended above this note as each release is cut. `cliff.toml`'s `header` is
deliberately empty so this heading is written once, here, rather than
re-emitted (and duplicated) by every `git cliff --prepend` run -- see
`cliff.toml` for the reasoning.
